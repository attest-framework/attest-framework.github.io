Adapters turn your provider's response or your framework's run into an Attest trace. Use a provider adapter for one model call, a framework adapter for a full run, or the manual builder when you control the instrumentation.

For Python, install the extra for the integration you use:

```bash
uv add "attest-ai[openai]>=1.1.0" pytest
```

The [SDK adapter guide](/sdk-guides/framework-adapters/) has the complete examples and capture limits for each integration. It covers provider responses, LangChain callbacks, CrewAI, Google ADK, LlamaIndex and OpenTelemetry. A trace records the evidence available from the integration; it does not prove that every tool call or side effect was captured.

Start with the [Python setup](/getting-started/python/) or [TypeScript setup](/getting-started/typescript/) for an evaluated test. OpenAI, Anthropic and manual adapters are stable; other adapters have beta or experimental status as shown above.
