## rec → replay → gate

A support agent refunded a customer twice after a payment timeout. Its output-only tests stayed green. That synthetic incident — [INC-1042](https://github.com/attest-framework/refund-desk/issues/2) — becomes a regression test in three moves:

<div class="story-strip">
  <div class="story-step rec">
    <span class="step-glyph">● rec</span>
    <h3>Capture the incident</h3>
    <p><code>attest capture</code> records the trace and model exchanges, applies redaction and drafts contracts from the run. A fixture marked consistent with the recording is not proof that the behavior is correct: review the fixture and choose independent business invariants.</p>
  </div>
  <div class="story-step play">
    <span class="step-glyph">▶ replay</span>
    <h3>Replay in CI</h3>
    <p>Strict replay runs your agent's real code against recorded model responses through a local proxy, with zero live model calls for matching requests. It removes live-model variability, not other sources of flaky tests; tool dependencies and test isolation still need control.</p>
  </div>
  <div class="story-step gate">
    <span class="step-glyph">✓ gate</span>
    <h3>Gate the merge</h3>
    <p>Checks report <span class="verdict pass">pass</span>, <span class="verdict fail">fail</span> or <span class="verdict skip">not_evaluated</span> with a reason. Failed tests block by default (<code>tests_failed: block</code>); <code>not_evaluated</code> warns unless the policy sets <code>not_evaluated: block</code>. Require the policy check in branch protection. The gate covers the contracts and baselines you supply, not every possible regression.</p>
  </div>
</div>

## Six evaluated layers plus plugins

The replay and gate run on deterministic checks. The layers are the full ladder of checks a contract or test can use, from free and instant to LLM-judged. Plugins add your own assertions. The table is generated from `attest-engine capabilities --json`.

## What it looks like

### Python

```python
from attest import agent, expect

@agent("weather-agent")
def weather_agent(builder, query: str) -> dict:
    # Recorded sample data: no model or weather API is called.
    builder.add_tool_call(
        "get_weather",
        args={"city": "Tokyo"},
        result={"temperature_c": 22, "conditions": "Sunny"},
    )
    return {
        "message": "Current weather conditions in Tokyo: sunny, 22°C.",
        "structured": {"city": "Tokyo", "temperature_c": 22},
    }

def test_weather_agent(attest):
    result = weather_agent(query="What's the weather in Tokyo?")

    chain = (
        expect(result)
        .required_tools(["get_weather"])                          # L3, free
        .output_contains("Tokyo")                                 # L4, free
        .output_matches_schema({                                 # L1, free
            "type": "object",
            "required": ["city", "temperature_c"],
            "properties": {
                "city": {"type": "string"},
                "temperature_c": {"type": "number"},
            },
        })
    )
    attest.evaluate(chain)
```
Save this as `test_weather_agent.py`, install `attest-ai==1.1.0rc5` and `pytest`
with `uv add`, then run `uv run pytest -v`. Every assertion above is deterministic
and requires no API key. For semantic checks, add `output_similar_to` or
`passes_judge` after configuring the corresponding embedding or judge provider.


### TypeScript

```typescript
import { agent, attestExpect } from '@attest-ai/core';
import { evaluate } from '@attest-ai/vitest';

const weatherAgent = agent('weather-agent', (builder, args) => {
  // Your agent implementation: record tool calls on the builder
  builder.addToolCall('get_weather', { args: { city: 'Tokyo' } });
  return { message: '...' };
});

test('weather agent returns weather data', async () => {
  const result = weatherAgent({ query: 'What is the weather in Tokyo?' });

  const chain = attestExpect(result)
    .requiredTools(['get_weather'])                               // Layer 3: Free
    .outputContains('Tokyo')                                      // Layer 4: Free
    .outputSimilarTo('Current weather conditions in Tokyo')       // Layer 5: cost depends on the embedding provider
    .passesJudge('Provides accurate, helpful weather information'); // Layer 6: cost depends on the judge provider

  await evaluate(chain);
});
```
